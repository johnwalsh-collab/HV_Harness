# Worked example — caspase genes in polyploid carp

The full worked example lives in the companion project folder `Caspase-Char/`,
which contains:

- `results/identification/Cgib_caspase_curation.md` — the per-pair curation document
- `results/explorers/Cgib_caspase_hierarchy.html` — the interactive hierarchy explorer
- `results/identification/caspase_gene_inventory.tsv` — the full gene inventory
- `config/caspase_example.yaml` — the config that drove this example (also in `HV_Harness/config/`)
- `Project Diary/` — a chronological record of the analysis

The `caspase_example.yaml` in `HV_Harness/config/` is the same file —
kept here so it can be read alongside the scripts and playbook that consumed it.
